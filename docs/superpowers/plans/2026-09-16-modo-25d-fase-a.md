# Modo 2.5D · Fase A — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un tablero puede crearse como 2.5D y, al abrirlo, el motor del diorama (portado a three r170 y troceado en `public/js/d3/`) renderiza un terreno de muestra dentro del shell de JA-VTT, sin HUD propio y sin persistir todavía.

**Architecture:** El servidor guarda `mode` en `boards.settings` (inmutable). El cliente clásico (`core/render/editor/main`) detecta `S.mode==='2.5d'`, oculta los canvas 2D y delega en `window.D3` (módulo ES `public/js/d3/index.js`). El motor se porta primero como un único módulo (`engine.js`) que funciona, y después se trocea en módulos con estado compartido en `ctx.js` (`G`), verificando con capturas que nada cambia.

**Tech Stack:** Node 22, PostgreSQL 16, `node:test`, three.js r170 (módulo ya vendorizado), Playwright + Edge (`npm run test:ui`).

**Spec:** `docs/superpowers/specs/2026-09-16-modo-25d-design.md`

## Global Constraints

- Una dependencia de producción (`pg`). Sin bundler. three.js **sólo** `public/js/vendor/three.module.min.js` (r170); el `three.min.js` r128 del diorama **no** entra al repo.
- Todo el SQL en `server/db.js`; reglas en `server/rules.js`. Esta fase **no** añade migraciones (`terrain` es fase B).
- Test primero; cada test roto una vez a propósito; `npm run check` verde antes de cada commit. Tests necesitan el Postgres `jav-test-pg` (ver `docs/05-runbook.md`).
- Cambios de cliente → `npm run test:ui` verde antes de desplegar.
- Comentarios y textos de UI en castellano, estilo del código existente (líneas densas, sin punto y coma final en cliente clásico; módulos ES con `;`).
- `diorama-jav/` es **fuente de lectura**, no se copia entera: entra al `.gitignore` en la Tarea 3.
- Lo que en el diorama era `flashHint(msg)` pasa a `opts.toast(msg)` (el `toast` de JA-VTT). Nada del motor toca el DOM salvo su propio `<canvas class="d3">` y los listeners sobre `#stage`.
- Limitación declarada de fase A: no hay fichas, ni luces, ni edición, ni niebla por jugador. Vista = director para todos. Terreno = escena de muestra «Valle del arroyo» del diorama.
